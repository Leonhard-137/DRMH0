# 两个候选 ridge proposal 的数学审查与 toy 检查

结论：在当前先验下，OU 提议的 `logH=0`；慢 GP 提议的 `logH=2s`。两项都是原目标分布的合法候选更新，但尚未接入当前采样器，也没有据此启动科学拟合。这里的正确性是目标分布保持，不是混合速度改善的保证。

## 统一约定

从与当前状态无关的对称密度抽取 s，即 g(s)=g(−s)，并把辅助变量反向映射为 −s。先计算候选；任何参数越界就拒绝整步，不反复重抽 s，其他坐标不变。候选 move 的选取概率也应与状态无关。

这类更新沿低维方向移动，不能直接当作全参数空间中有普通密度的独立 proposal。使用增广可逆映射

\[
F:(x,s)\mapsto(T_s(x),-s),\qquad F(F(x,s))=(x,s)
\]

可得严格接受因子

\[
H=\frac{p(T_s(x))}{p(x)}\frac{g(-s)}{g(s)}
\left|\det D F(x,s)\right|.
\]

p 为原先验；普通 MH 还乘完整似然比，DNest 则同时检查当前层的硬似然下限。以下 `logH` 仅是传给 CDNest 的先验与 proposal 校正，不包含完整似然比。

## OU 长时间尺度提议

令 σ=σx、τ=τx，更新

\[
\sigma'=\sigma e^s,\qquad \tau'=\tau e^{2s}.
\]

当前两者都是有限区间上的 log-uniform 先验，故 p(σ,τ)∝1/(στ)。增广 Jacobian 的绝对值为 e^(3s)，先验密度比为 e^(−3s)，所以 H=1，**logH=0**。等价地，在 `(log σ, log τ)` 的均匀先验坐标中，这就是对称平移 `(s,2s)`。

OU 结构函数为

\[
\mathrm{SF}^2(\Delta t)=2\sigma^2(1-e^{-|\Delta t|/\tau})
\simeq 2\sigma^2|\Delta t|/\tau.
\]

当 τ 比涉及的时间差、响应核尺度足够长时，这一步精确保持近似项中的 σ²/τ。它不精确保持整个 OU 协方差或卷积似然；仍需照常计算完整似然。这一提议可用于 none、independent、shared 三种模式，因为共同 OU 的参数与先验相同。

## 慢 GP 长时间尺度提议

更新

\[
q_W'=q_W e^s,\quad q_b'=q_b e^s,\quad T_s'=T_s e^s.
\]

当前 qW、qb 各为 uniform [0,2.5]，Ts 为 log-uniform [5,120]。因此联合物理坐标先验密度只含 1/Ts：在两端均有效时，先验比是 e^(−s)。三个坐标的增广 Jacobian 为 e^(3s)，得到

\[
H=e^{2s},\qquad \boxed{\log H=2s}.
\]

另一个推导是在 `(log qW, log qb, log Ts)` 中，先验密度正比于 qW qb；对称平移 `(s,s,s)` 使其比值为 e^(2s)。这里不允许把 uniform q 错当成 log-uniform。恰为零的 q 保持为零；这些面在当前连续先验下测度为零，而且这个单一 ridge move 本身不能独立保证遍历性。

当前代码的 Matérn-3/2 核为 `k(h)=q²(1+|h|/Ts) exp(−|h|/Ts)`，其导数方差为 `−k''(0)=q²/Ts²`。已核实 `core.py:16–17,176–185`；这里的 Ts 等于常见标准 lengthscale ℓ 除以 √3。只有写成 `q²(1+sqrt(3)|h|/ℓ) exp(−sqrt(3)|h|/ℓ)` 时，导数方差才是 `3q²/ℓ²`。先前说明把 Ts 误当作 ℓ，现予以更正。

因此两波段各自的导数方差在候选映射下不变。independent 模型的两慢过程彼此独立，分别保持 `q_i²/Ts²`；shared 模型另外有导数交叉协方差 `qW qb/Ts²`，同样不变。这个时间尺度约定的修正不改变缩放不变量或 `logH=2s` 的推导。

两种模式的 `logH` 相同，因为当前实现已经边缘化 GP 路径，更新的只是相同先验下的三个超参数，没有额外缩放被采样的隐过程坐标。完整协方差中的常数项和高阶时间依赖并不全部保持。两个自由常数均值已边缘化有助于解释长时间尺度近似，但不构成精确似然对称。

如果将来更改 q 或 Ts 的先验，必须重算校正。例如三者全为 log-uniform 时这一提议才是 logH=0；当前先验绝不能采用该值。如果在边界处反复重抽直到有效，g 会变为状态相关的截断密度，还必须加入截断归一化因子之比。当前候选采用直接越界拒绝，避免这个变化。

## CDNest callback 与拒绝语义

已只读核对本地原始实现：

- `CDNest/python/cydnest/PyFuncs.h:90–125` 的 `py_perturb` 从 Python 返回值读取浮点 `log_H`，把 Python 修改后的坐标复制到 C 的候选缓冲区，然后原样返回 `log_H`。没有把非零值忽略或强制设零。
- `CDNest/src/dnest.c:733–776` 的 `update_particle_normal` 先分配候选缓冲区并复制当前粒子；调用 perturb 后仍会计算候选似然，再将正 `log_H` 截为零，并以 `exp(min(0,log_H))` 的概率及当前层硬似然条件决定接受。仅接受分支把候选复制回粒子，拒绝不修改原粒子。

候选接入时可先在局部变量中计算新值；越界就不写入坐标并返回 `-inf`。C 层即使收到 `-inf` 也仍会调用似然，因此不要用返回值假定似然求值会被跳过。Python 传入的数组和 C 候选缓冲区都不是已接受粒子的原位视图；正常拒绝无需手工恢复原粒子。统计计数或其他 callback 副作用不会因拒绝自动回滚，提议函数应只改候选坐标和明确的尝试计数。

## 已完成的低成本 toy 检查

脚本为同目录 `check_candidate_ridge_proposals.py`，输出为 `/home/leonhard/sci001/output/mica_slowgp/sampler_smoke/candidate_ridge_proposals/checks.json`。它不导入科学采样器或科学似然，使用当前相同类型与边界的先验；s 从与状态无关的 N(0,0.55²) 抽取。检查包含：

1. 正反映射恢复、增广 Jacobian 的有限差分及先验密度比恒等式。
2. 原先验、可精确抽样的硬约束层 `U0+U1>1`、可精确抽样的非平坦目标 `prior × exp(k·U)`，各 120,000 个独立初始样本；执行一次正确 MH/DNest 层更新后，用精确概率积分变换核对分布不变性与反对称详细平衡矩。
3. 刻意将慢 GP 校正错置为 logH=0 的负对照。

正确实现的六组目标检查全部通过：最大均值偏差 2.47 个标准误，最大 KS 距离 0.00458，最大详细平衡矩偏差 2.30 个标准误；预设阈值分别为 6、0.015、6。反向映射最大相对误差 2.58×10⁻¹⁶，Hastings 恒等式最大误差 7.07×10⁻¹⁶，Jacobian 数值检查最大相对误差 2.30×10⁻¹⁰。

省掉慢 GP 的 2s 校正后，先验一步不变性明显失败：三个边际均值偏差约 43–50 个标准误，最大 KS 距离 0.0680，详细平衡矩偏差 33.4 个标准误。因此 `logH=2s` 是必要的目标分布校正，不能为了提高接受率省掉。

这些 toy 结果补充解析推导，不测量科学后验的混合速度；其中的接受率也不是科学拟合接受率。当前 sampler.py、模型、先验和正在运行的代码均未修改，候选是否接入仍等待当前独立后端结果与后续决定。
