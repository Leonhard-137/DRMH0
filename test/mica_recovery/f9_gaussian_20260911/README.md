# F9 旧注入实验：双高斯恢复对照

复用 `../f9_all_bands/manifest.json` 索引的 25 次双 Gamma 拟合的实际输入；M2/B 来自 `../f9_m2_b`，W1/U/V 来自 `../f9_all_bands`。逐字节复制旧运行的 `input/cont.txt` 与 `input/line.txt`，不重新生成驱动、独立信号、采样或噪声。

## 范围与顺序

每个条件均拟合 M2、W1、U、B、V，共 25 次 W2–目标波段成对拟合：

1. `random_within`：目标端独立慢信号，较短一档。
2. `random_beyond`：目标端独立慢信号，较长一档。
3. `disk_only`：纯盘基线。
4. `response_within`：目标端真实慢响应，较短一档。
5. `response_beyond`：目标端真实慢响应，较长一档。

W2 构造保持旧实验；这与 Mrk817 的参考波段污染实验是两个批次。

## 先验与采样

- 两个正幅度 Gaussian 核，两质心均在观察者系 `[-10, 2000] d`，保持旧 Gamma 质心先验。
- 旧 shape=2 Gamma 的原生尺度 w 为 log-uniform `[0.01, 1200] d`，标准差为 sqrt(2)*w。Gaussian 的原生宽度即标准差，所以使用 log-uniform `[0.0141421356, 1697.056275] d`。原生参数写入有六位小数舍入。
- 幅度、噪声、趋势等其余设置与旧实验一致。两核可交换，解释 short/long 时应按每个后验样本质心排序整组参数。
- 每次 2 个 MPI 进程，每进程 1 个粒子，10,000 saves，ptol=0.1，沿用用户最近一粒子要求。旧 Gamma 每进程 4 个粒子；比较时必须检查有效样本数、竞争解和恢复偏差，不能把全部差异直接归因于核形状。
- 相同保存数并不意味着相同计算预算，粒子减少也会减少每次保存之间的提案数。新运行还会重新进行 continuum 预拟合：虽使用相同 W2 和同一算法，DRW 有效先验仍可能有蒙特卡洛差异，应比较新 `data/continuum_prior.json` 与旧结果的实际 continuum 后验。
- 继承的 `[-100, 500] d` 转移函数绘图范围只控制图示，不能据此判断宽尾不存在；后续对比需显示完整宽度范围。

## 运行与状态

使用 astro Python 执行 `run_experiment.py --prepare` 准备，`--validate-only` 只读核对，`--detach` 后台排队。无需外层 mpiexec。

控制器等待 `../mrk817_w2_thermal_20260910` 队列成功完成、释放锁且输出通过验证，再同时运行最多 10 个 F9 拟合。等待时不启动 MICA；正式计算调用 `src/run_mica.py`。复用 Mrk817 的队列函数，但所有状态、锁、日志与输出指向本目录，不修改其源文件或运行任务。

状态见 `queue_state.json`，控制器日志 `controller.log`，各任务日志 `logs/`。若旧队列失败或中断，本批保持等待；若本批失败，保留检查点，排查后显式 `--detach --retry-failed` 恢复。已有成功结果不覆盖。

## 结果要回答的问题

对照独立信号两档与纯盘基线，检查短质心和幅度恢复误差、第二组分宽度/质心/幅度后验、分量光变与已知盘光变差异；再用真实慢响应两档区分核的恢复能力与独立信号吸收现象。真值沿用旧 manifest 的 truth_file。本批仍只有同一组配对随机实现，不能给出跨实现稳定性或覆盖率。
